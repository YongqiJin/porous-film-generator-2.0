# Examples

## `configs/`

Ten schema-v3 parameter sets used for morphology exploration. Values are examples, not calibrated material parameters.

## `visual-only-failed-audit/`

Three GLB files and their status JSON. They are useful for Blender inspection of generated morphology, but all three are explicitly `completed_infeasible` / validator `FAIL`. Do not use them as accepted scientific structures.

## `synthetic-validator-pass/`

A small test-created schema-v3 QA bundle that passes the independent validator. It demonstrates file names and data contracts only. It is not a real generator calibration, not a physical material, and not evidence that production-sized targets are feasible.
