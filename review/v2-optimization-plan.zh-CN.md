# Porous Film Generator 2.0 优化分析与实施方案

> 基线：Porous Film Generator 2.0，Git 提交 `1c9a10793e96437202482ec44e4263b87ef64882`，输入 schema v3，Python 包版本 `0.4.0.dev1`。  
> 编制日期：2026-08-31。  
> 范围：孔结构生成算法、最终结构审核、候选搜索及计算性能；不包含分子填充和下游电热性质模型。

## 1. 问题定义

### 1.1 总体目标

给定薄膜尺寸、目标孔统计分布和拓扑约束，生成一个三维二值孔相，使最终体素结构经过独立重测后同时满足：

- 目标孔隙率；
- z 方向孔贯通要求；
- 半导体相沿 x 方向贯通及最小 yz 截面要求；
- 贯通孔中心距离、局部等效直径、方向、长细比、曲折度和曲率波动等目标分布；
- 重叠、网格稳定性、可复现性和导出一致性要求。

优化目标不是让生成单元的抽样参数接近输入，而是让**最终合并、裁剪和体素化后的孔相测量值**接近输入。

### 1.2 输入

#### 正式物理输入

| 类别 | 输入 | 含义 |
|---|---|---|
| 几何边界 | `film.target_box_A` | 真实薄膜计算盒；x/y 周期、z 有限 |
| 位置—数量 | `g_xy(r)` | 同一 z 截面内不同贯通孔中心线的周期 xy 距离分布 |
| 尺寸 | `p_D(D_eq)` | 沿最终中心线法向截面的局部等效直径分布 |
| 方向 | `p_ori(theta_xz, theta_xy)` | 同一三维孔轴的成对投影角联合分布 |
| 紧凑孔形状 | `p_eta,c` | 最终紧凑孔主轴与横向尺度之比 |
| 通道形状 | `p_eta,ch` | 中心线弧长与通道级等效直径之比 |
| 通道曲折度 | `p_tau` | 中心线弧长与端点直线距离之比 |
| 表面复杂度 | `p_kappa(w)` | 法向截面边界的相对曲率波动分布 |
| 占比 | `Phi_V` | 最终孔相体积分数 |
| 硬约束 | matrix/topology constraints | 孔贯通、半导体贯通、最小截面、重叠等 |

#### 内部生成控制量

以下变量可以优化，但不能直接当作最终结果：

- 生成单元数量或密度；
- 通道/紧凑单元比例；
- 锚点位置和排斥强度；
- 通道控制点、半径结点和支路数量；
- 紧凑孔叶瓣数、叶瓣位置和形状种子；
- roughness 幅度；
- 候选随机种子和全局尺度。

### 1.3 输出

#### 权威科学输出

- `final_phase.h5`：最终二值孔相；
- `final_centerlines.h5`：从最终孔相提取的中心线；
- `final_cross_sections.csv`：法向截面、直径和曲率结果；
- `final_measurements.json`：最终测量汇总；
- `feasibility.json`：所有正式目标及硬约束的通过状态；
- 独立 validator 的 PASS / FAIL / NOT_EVALUABLE 结果。

#### 诊断和可视化输出

- 单元几何和 shape seed；
- GLB/PLY；
- 候选历史、失败原因、阶段耗时和峰值内存；
- 输入、最终测量和约束违反量的对照报告。

### 1.4 成功标准

一个样本只有在以下条件同时满足时才算成功：

1. 命令正常结束；
2. 最终孔相存在且可复现；
3. 所有硬约束通过；
4. 每项正式分布有足够有效样本并通过统计阈值；
5. 粗细网格测量稳定；
6. 独立 validator 通过。

GLB 可以打开、孔隙率接近目标或程序退出码为 0，都不能单独证明科学可行。

## 2. 当前方法

### 2.1 当前流水线

1. 严格解析 schema v3 配置并执行预检查。
2. 根据 `seed_number_density_A3 × box volume` 决定生成单元数。
3. 随机放置三维锚点，并通过退火式移动使锚点 RDF 接近目标。
4. 用分层分位点抽样分配孔型、尺寸、方向、eta、tau 和曲率目标。
5. 构造多叶紧凑孔或三维多弯、变半径通道。
6. 对全部单元及周期像的 SDF 使用 smooth-min 合并。
7. 通过全局尺度二分和反复体素化，使孔隙率进入容差。
8. 从最终相位逐 z 层识别孔中心并追踪中心线。
9. 沿中心线构造法向截面，测量直径、曲率、方向、eta 和 tau。
10. 比较正式分布并检查半导体连通、截面和网格稳定性。
11. 在候选中选择第一个全部通过者；若均失败，则选择孔隙率最接近者。
12. 对选中候选完整重放，写出产物并运行独立验证器。

### 2.2 当前形状模型

#### 多叶紧凑孔

- 2–4 个椭球叶瓣；
- 随机父子连接并主动形成腰部；
- PCA 对齐后进行仿射缩放；
- smooth-min 合并叶瓣；
- 使用固定 Sobol 点估计体积并缩放至目标体积；
- 最多重试 16 次，失败时整个候选失败。

#### 多弯变半径通道

- 使用 7 个控制点；
- y/z 横向位移由低阶正弦模式构造；
- 通过根求解振幅匹配目标 tau；
- 使用 PCHIP 表达变半径；
- 检查弯折数、非平面性和非相邻管段自交；
- SDF 内部已有段级 AABB 裁剪。

### 2.3 当前搜索方法

- 单元参数采用分层抽样；
- 锚点使用简单模拟退火；
- 孔隙率使用一维全局尺度二分；
- 其他正式目标没有闭环优化；
- 候选之间仅通过不同随机 seed 探索；
- 全部候选失败时，只按孔隙率误差回退。

## 3. 当前运行证据

三个 3 × 3 × 0.6 μm 示例均能生成可视化结构，但没有通过严格审核：

| 样例 | 单元数 | 贯通中心线 | 总耗时 | 峰值内存 | 结果 |
|---|---:|---:|---:|---:|---|
| A01 dispersed-worms | 43 | 0 | 1895 s | 3436 MiB | FAIL |
| A02 rounded-rods | 40 | 2 | 2216 s | 3613 MiB | FAIL |
| A03 fine-dispersed | 49 | 0 | 1321 s | 3920 MiB | FAIL |

单候选的 `candidate_wall_time` 大约只有 `generation_total` 的一半，说明选中候选的完整 replay 几乎把几何计算执行了两遍。独立 validator 仅占约十几秒，不是当前首要性能瓶颈。

## 4. 核心卡点

### 4.1 生成空间与目标空间不一致

- 生成阶段优化的是单元锚点 RDF；审核阶段使用最终贯通中心线的逐层 RDF。
- 单元重叠、连接和边界裁剪后，两者不存在稳定的一一映射。
- 方向和 eta/tau 在单元上采样，但审核只统计最终保留下来的贯通轨迹。
- 紧凑孔没有由正式直径目标直接控制。
- roughness 到曲率波动只有未经标定的经验映射。

### 4.2 贯通拓扑依赖随机碰撞

当前通道从盒内随机锚点出发，具有随机方向和有限长度，没有先构造连接 z 下表面与上表面的主骨架。因此零贯通轨迹不是偶发异常，而是当前生成方式下的高概率结果。

### 4.3 孔隙率修正会扰动其他目标

统一缩放会同时改变：

- 局部等效直径；
- 通道长度和空间覆盖；
- 单元重叠、合并和截断；
- 贯通概率与半导体连通性。

因此孔隙率虽然更接近目标，其他正式分布可能变得更差。

### 4.4 有效样本数量不足

正式形状统计只使用贯通轨迹。贯通轨迹为 0–2 条时，直径、方向、eta/tau、曲率和 `g_xy` 要么无样本，要么统计波动极大。固定 KS/Wasserstein 阈值在这种样本量下缺少稳定性。

### 4.5 搜索没有利用失败信息

当前候选之间互相独立。一次候选得到的“方向偏小、直径偏大、无贯通、重叠过高”等信息不会反馈给下一候选。增加候选数只是增加抽奖次数。

### 4.6 主要性能浪费

1. 选中候选被完整重放一次。
2. 孔隙率二分期间多次执行全网格 SDF。
3. 审核阶段重复生成 coarse/fine grid；另有一次 coarse grid 结果被直接丢弃。
4. 全局 SDF 遍历全部孔单元和周期像，并保存大规模中间矩阵。
5. overlap 审核按“每个单元 × 全部体素”重新计算覆盖。
6. RDF 退火每移动一个点都重算所有点对和固定 Sobol 参考。
7. 每个法向截面都重新把完整三维 bool mask 转成 float。
8. 周期距离变换使用 3 × 3 xy 平铺；local-thickness 还包含逐半径、逐球写入循环。
9. 当前并行只覆盖候选或 seed；单候选无法有效使用多核。
10. 内存预估只覆盖少量规则网格数组，未覆盖 SDF、SciPy、轮廓和进程临时量，和实测峰值相差很大。

## 5. 改进方法：生成算法

### 5.1 P0：补齐科学语义和审核门

在修改生成器前，先补齐以下契约：

- 增加 `require_z_percolation`、最少贯通轨迹数或贯通孔体积分数；
- 实现最终紧凑孔分类与 `eta_c` 测量；
- 对 `(theta_xz, theta_xy)` 做二维联合分布检验，而不是只比较两个边缘分布；
- 将 `maximum_overlap_fraction` 纳入 schema v3 的正式通过判定；
- 为所有分布设置最低有效样本数；
- 报告置信区间或 bootstrap 不确定性，区分“确实不匹配”和“样本不足”；
- 对输入做物理可行性预检查，例如膜厚、直径、eta/tau 和方向支持区间能否允许 z 贯通。

### 5.2 P1：拓扑优先生成

将“独立单元随机叠加”改为“贯通骨架优先”：

1. 根据目标样本量确定 z 贯通主通道数。
2. 在 z 下表面和上表面生成成对孔口。
3. 用三维 spline、Fourier 模式或受约束随机桥连接孔口。
4. 联合调整整组中心线，使各 z 层汇总后的 `g_xy(r)` 接近目标。
5. 沿中心线直接赋予半径场，使局部截面样本匹配 `p_D`。
6. 通过弧长、端距和半径联合控制 eta/tau。
7. 在主骨架建立后再增加支路、紧凑孔和局部形状。
8. 每次局部修改后增量检查孔贯通和半导体连通约束。

该方法使贯通成为构造条件，而不是生成后的偶然结果。

### 5.3 P1：孔隙率改为体积预算

不再主要依靠全局尺度纠偏：

- 先从目标直径、eta/tau 和通道数量计算理论体积预算；
- 估计重叠和边界裁剪损失；
- 通过调整通道数量、支路数量、紧凑孔数量及分位点分配满足孔隙率；
- 只允许很小的末端尺度修正，并在修正后重新检查直径分布。

### 5.4 P1：多目标闭环优化

定义归一化损失：

```text
L = hard_constraint_penalty
  + w_rdf * L_gxy
  + w_D * L_D
  + w_ori * L_joint_orientation
  + w_eta_c * L_eta_c
  + w_eta_ch * L_eta_ch
  + w_tau * L_tau
  + w_kappa * L_kappa
  + w_phi * L_porosity
```

选择规则采用 constraint domination：硬约束可行者始终优于不可行者；同一可行层级内再比较分布损失。

优化器首版建议使用 CMA-ES、约束贝叶斯优化或分层坐标搜索，不要求可微。每次 coarse-grid 测量结果都反馈给下一批候选。

### 5.5 P2：建立 roughness 标定模型

离线扫描以下变量：

- roughness 幅度；
- 等效直径；
- 截面形状；
- 体素间距；
- 边界重采样与平滑尺度。

建立 `target curvature → roughness` 的单调查找表或轻量代理模型。正式生成时使用反演结果，最终仍以独立测量为准。

## 6. 改进方法：计算加速

### 6.1 第一批低风险优化

1. **复用网格：**孔隙率求解产生的 fine grid 直接传给审核；coarse grid 只计算一次。
2. **取消生产路径的完整 replay：**worker 写出不可变候选产物，父进程验证配置、身份、phase hash 和指标后原子发布；完整 replay 保留在 CI 或抽样审计模式。
3. **缓存 RDF 固定量：**Sobol 参考直方图、分箱边界和目标曲线只计算一次。
4. **增量 RDF：**移动一个点时只更新该点相关的 `N-1` 个距离，将中心退火从近似 `O(N^3)` 降为 `O(N^2)`。
5. **缓存测量数组：**每个 grid 只执行一次 mask 浮点转换；法向截面批量采样。
6. **完善阶段计时：**至少记录中心生成、形状生成、每次 scale evaluation、fine/coarse voxel、最终测量、overlap、local thickness、导出和 validator。

### 6.2 SDF 与体素化优化

- 为每个孔单元构造全局扩展 AABB；
- 用 uniform grid、空间哈希或 BVH 查询每个 voxel tile 的候选单元；
- smooth-min 使用流式累积，避免 `unit_count × voxel_count` 的完整中间矩阵；
- 按三维 tile/slab 体素化，提高缓存局部性；
- scale evaluation 复用不随尺度变化的方向、拓扑、局部 frame 和归一化 profile；
- 先用粗网格或确定性采样点定位尺度区间，最后只做少量 fine-grid 求值；
- overlap 仅在各单元 AABB 覆盖区域内累加，而不是每个单元扫描全盒。

注意：直接把 smooth-min 改成二值 OR 或 hard-min 会改变几何，应视为算法变更并重新验证，而不是纯性能优化。

### 6.3 最终测量优化

- z-slice 中心识别按切片并行；
- 使用有限周期 halo，避免所有切片固定 3 × 3 平铺；
- 中心 refinement 使用周期 KD-tree、Voronoi 或 watershed，避免中心数 × 孔像素数的完整距离矩阵；
- 法向截面批量生成坐标并调用插值；
- local-thickness 改为 EDT 驱动的最大球传播算法；
- 以 `(phase_hash, measurement_contract_hash)` 缓存测量结果。

### 6.4 并行与加速后端

- 候选数大于 1 时继续使用候选级进程并行；
- 单候选时增加 voxel tile、z-slice 和 cross-section 级并行；
- 使用共享内存或只读 memory map，避免多 worker 复制完整 phase；
- 根据实测峰值而不是理论数组大小决定 worker 数；
- 完成 CPU 去重和空间裁剪后，再评估 Numba、C++ 或 GPU kernel。

GPU 优先覆盖 SDF 批量求值、体素化和规则插值。连通域、轮廓、匈牙利追踪及独立 validator 不必作为第一批 GPU 目标。

## 7. 需要的资源

### 7.1 人员能力

| 角色 | 主要工作 |
|---|---|
| 几何/科学负责人 | 确认正式参数、拓扑定义、样本权重和可行性边界 |
| 数值算法工程师 | 拓扑生成、反演、SDF、空间索引和多保真优化 |
| 科学计算工程师 | NumPy/SciPy 性能、并行、内存和可复现性 |
| 验证负责人 | 独立 oracle、测试数据和接受阈值 |

小团队可以由同一人兼任，但生成器实现和独立验证逻辑必须保持审查隔离。

### 7.2 计算资源

- 开发与单元测试：8–16 核 CPU、32 GB RAM；
- 真实尺寸 CPU 基准：32–64 核 CPU、128 GB RAM；
- GPU 试验：至少一张支持双精度或稳定 FP32 的 CUDA GPU，并保留 CPU 暴力参考；
- 持久化存储：保存固定配置、phase、测量、日志和 profile，不提交大规模生成结果到源码仓库。

### 7.3 数据与基准

至少建立以下固定集合：

- 解析几何：球、椭球、直圆柱、倾斜圆柱、已知曲率截面；
- 拓扑几何：单贯通、双贯通、分支、合并、闭环、孤立孔；
- 边界几何：跨 x/y 周期边界和接触 z 表面；
- A01–A03 历史样例；
- 一个确保可通过的真实 schema v3 样例；
- 大、中、小三档分辨率的性能矩阵；
- 至少 10–30 个固定 seed 的可行率面板。

### 7.4 工具

- `pytest`、Ruff 和现有独立 validator；
- `cProfile`/py-spy/scalene 等 CPU 与内存 profiler；
- 阶段级 wall/CPU/RSS 记录；
- 可选 Numba/C++/CUDA 原型；
- 自动生成的目标—实测曲线、误差和可行性报告。

## 8. 验证方法

### 8.1 科学正确性

1. 每个正式输入都有同义的最终相测量。
2. 测量器不读取生成目标、标签、shape seed 或预写指标。
3. 目标配置改变而 phase 不变时，测量值必须保持不变。
4. 解析几何的直径、方向、eta/tau、曲率和连通结果与理论值一致。
5. 主程序和独立 validator 在明确容差内一致。
6. 缺少有效样本时返回明确失败或 NOT_EVALUABLE，不伪装成通过。

### 8.2 算法效果

对固定设计和 seed panel 比较：

- z 贯通成功率；
- 硬约束通过率；
- 全目标联合通过率；
- 各分布 KS、归一化 Wasserstein 或二维联合距离；
- 有效中心线和截面样本数；
- 候选达到可行解所需评估次数；
- 不同 seed 的均值、方差和失败模式。

### 8.3 性能验证

固定 YAML、seed、Python 和依赖版本，分别记录：

- 端到端 wall time；
- CPU time；
- 峰值 RSS；
- 每个阶段耗时；
- 完整体素化次数；
- SDF 点—单元和点—segment 评估数量；
- 单核、单候选多核、候选并行的扩展效率。

### 8.4 等价性验证

纯性能改写必须满足：

- 与暴力 SDF 参考逐点比较；
- phase mask 相同，或差异严格限制在预先声明的边界容差内；
- 相同 seed 的候选身份和随机流不变；
- 最终指标、审核结果和 validator 结论不变；
- 串行与并行结果一致；
- 输出 schema 和校验和规则不变。

GPU 或降低精度造成的差异必须单独作为科学行为变更评审，不能混入普通性能重构。

## 9. 分阶段实施计划

### 阶段 A：建立可信基线

- 增加完整阶段计时和 profile；
- 建立解析、小型、真实尺寸三档基准；
- 增加一个可稳定通过的 schema v3 标准样例；
- 修正内存估算模型。

交付：性能基线表、失败类型分布、固定输入和输出 hash。

### 阶段 B：修复 P0 语义缺口

- z 贯通硬门；
- compact eta 最终测量；
- 联合方向检验；
- overlap 通过门；
- 最低样本数与统计不确定性；
- 综合候选评分。

交付：所有正式输入均有明确、可执行的最终相验收定义。

### 阶段 C：低风险性能优化

- 去除重复 voxelization；
- 取消生产路径完整 replay；
- RDF 缓存与增量更新；
- 流式 smooth-min；
- mask 和测量缓存；
- AABB 限域 overlap。

交付：在科学结果不变的前提下降低单候选时间和峰值内存。

### 阶段 D：拓扑优先生成和闭环优化

- 构造 z 贯通主骨架；
- 直接分配截面直径和路径属性；
- coarse-grid 多目标反馈；
- roughness 标定；
- 约束优化器和动态候选预算。

交付：显著提高 seed panel 的联合通过率，减少无效候选。

### 阶段 E：编译与 GPU 加速

- 根据 profile 选择 SDF、体素化和截面采样热点；
- 建立 CPU reference 与加速 kernel 的差分测试；
- 对生产规模评估吞吐、内存和成本。

交付：可选的高速后端，并保持默认 CPU reference 路径。

## 10. 推荐优先级结论

1. 先补齐验收语义和 z 贯通构造，否则速度越快只会越快地产生不合格候选。
2. 性能侧先做 replay、重复网格、RDF 固定量和 SDF 中间矩阵去重，这些收益明确且科学风险较低。
3. 随后实现 topology-first 生成和多目标闭环，这是提高可行率的核心。
4. GPU 放在 CPU 数据流和算法闭环稳定之后。
5. 所有优化都必须在固定配置和 seed 上同时报告科学结果、可行率、耗时、内存和独立验证结论。
