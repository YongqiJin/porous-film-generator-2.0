# Known issues and review priorities

Verified against Git tag `2.0` on 2026-08-31.

## P0 — scientific semantics

1. `formal_targets.shape.compact_aspect_ratio` is accepted and drives compact-unit construction, but the schema-v3 final-phase audit does not reconstruct or compare final compact-pore aspect ratio. `compact_eta_result` remains null in the v3 path.
2. Paired xz/xy orientation is sampled jointly, but final audit compares the two marginal distributions separately; it does not test joint pairing/correlation.
3. There is no explicit configurable hard gate requiring at least one pore component to span z. Through tracks are measured and required distributions usually fail when no through samples exist, but topology is not represented by a dedicated input field.
4. `matrix_constraints.maximum_overlap_fraction` is calculated but is not applied as a schema-v3 pass/fail gate in `_audit_final_geometry_targets()`.
5. `equivalent_diameter_A` directly controls channel construction, not compact-unit size; compact units are still sized through internal target volume and eta.
6. Curvature target to generation roughness is an uncalibrated heuristic: `min(0.25, 0.05 * target)`.

## P1 — search and feasibility

1. The only solved continuous internal variable is one global geometry scale for porosity. Other formal distributions are approached through random generation, not jointly optimized.
2. If no candidate passes, selection falls back to the successful candidate with closest porosity, not the closest total formal-target distance.
3. Formal shape samples are restricted to final through tracks; few/no tracks cause weak or missing statistics.
4. Existing 3 × 3 × 0.6 µm visual examples completed geometry generation but failed strict validation.

## P2 — API and maintainability

1. Generated Pydantic JSON Schema lists compatibility fields (`pores`, `center_distribution`, `compact`) as required even though the before-validator supplies them for schema-v3 YAML.
2. `output.root` and `output.write_plots` currently have no production effect; distribution plots are not generated by the package code.
3. `generate-geometry` and `generate` do not publish identical status/optimizer artifacts.
4. Main and independent measurement implementations contain substantial mirrored logic; synchronized defects are possible.
5. Official version 2.0, input schema 3, and package version 0.4.0.dev1 coexist.
6. No project LICENSE file is present.
