# 复杂孔形状生成 v1 设计规格

**日期：** 2026-08-20  
**分支：** `experiment/complex-shape-generation-v1`  
**基线：** 不可移动标签 `original-v0.2.0`  
**实验版本：** `0.3.0.dev1`

## 目标与边界

本分支只替换“已抽样参数如何映射为三维孔形状”。YAML schema、概率分布、分层抽样、混合分布整数分配、候选/seed 并行、全局尺度求解和 roughness 算法保持不变。

- 紧凑孔从单椭球改为体积归一化的多叶平滑连通孔。
- 通道孔从近似单平面恒定截面曲线改为三维多弯、变截面曲线。
- 手工 `CompactUnit.sphere()` 和不带半径 profile 的 `ChannelUnit.from_polyline()` 保持 v1 兼容。
- 只有 YAML 的 `build_units()` 自动生成复杂形状。
- 不实现 Y/树枝通道、孔内拓扑洞、属性协方差或新 roughness 模型。

## 紧凑孔

每个紧凑孔从主 RNG 派生内部 `shape_seed`，内部最多尝试 16 次：

1. 叶瓣数为 2/3/4，概率为 0.25/0.50/0.25。
2. 叶瓣相对尺度为 0.65–1.15。
3. 新叶瓣中心与已有父叶瓣的距离为两者尺度和的 0.58–0.82。
4. 按叶瓣体积权重重心归零，PCA 主轴对齐局部 z。
5. 仿射调整包络，使 x/y 横向包络相同、z/x 为抽样 `eta`。
6. smooth-min 长度为最小横向叶瓣半径的 0.12。
7. 固定无扰 Sobol `2^15` 点估计体积，并统一缩放到抽样 `p_V` 目标。
8. 要求叶瓣连通、包络 `eta` 误差不超过 5%、包络填充率为 0.50–0.85。

失败时该候选失败，不回退规则椭球。roughness 在多叶基底形成后按旧算法施加一次。

## 通道孔

每个通道从主 RNG 派生内部 `shape_seed`，内部最多尝试 16 次：

1. 使用 7 个控制点。
2. 局部 x 为端点主轴，y/z 由 1–3 阶低频正弦模式构成，端点回到主轴。
3. 根求解横向振幅，使弧长/端距等于抽样 `tau`。
4. `tau > 1.05` 时必须至少两个弯折且为非平面曲线；`1 < tau <= 1.05` 允许小幅弯曲，`tau=1` 数学上保留直线。
5. 7 个归一化弧长半径结点使用 PCHIP，无过冲；运行 SDF 沿弧长直接评估同一 PCHIP。
6. 相邻段用共享角平分面连接截面，仅全局两端使用半球端帽，使运行体积、HDF5 和解析积分一致。
6. 半径相对等效半径为 0.60–1.45，CV 为 0.15–0.30，且至少有一个鼓包和一个收颈。
7. 解析求解等效半径，使 `eta = 弧长/(2r_eq)`、`tau = 弧长/端距`，并保持理论目标体积。
8. 非相邻管段不得发生管体自交。

roughness 仍使用等效半径和旧算法，不承担宏观变截面。

## 内部模型与性能

`CompactUnit` 保存可选叶瓣中心、三轴半径、smooth-min 长度、包络和填充率。`ChannelUnit` 保存可选半径 profile，并在构造时缓存：

- 中心线采样段；
- 段首/段尾/段最大半径；
- 累计弧长；
- roughness 支持；
- 扩展 AABB。

通道 SDF 先使用 AABB 距离下界，只有可能影响当前 smooth-min 的段才执行完整局部坐标计算。跳过阈值由 smooth-min 指数尾项推导；与全段暴力参考的最大差异必须不超过 `1e-9 Å`。

紧凑孔周期查询对小于半盒尺寸的孔使用最小镜像并保留 smooth-min 尾项等价性。分子放置预计算复用一次大规模 SDF 网格，避免为体积、可达性和候选采样重复体素化。

## 输出契约

复杂 YAML 生成的 `unit_geometry.jsonl` 使用 schema v2：

- 公共：`shape_model`、`shape_seed`。
- 紧凑孔：叶瓣中心/半径、smooth-min 长度、包络半轴、填充率、重心和连通性。
- 通道：7 个控制点、等效半径、归一化弧长半径结点、实际半径、弯折、非平面和自交净距。

`channel_curves.h5` schema v2 为每条通道建立 group，至少含 `centerline_A` 与 `radius_A`。`pore_geometry.h5` 的几何 schema 为 v2；`contract.json` 与 `final_phase.h5` 相位契约保持原版本。

`main_unit_metrics.csv` 增加逐孔形状诊断，`realized_geometry_parameters.json` 增加 `shape_complexity_summary`。这些字段是诊断输出，不是新的 YAML/优化输入。

## 独立审核

独立 validator 不导入生成器几何实现：

- 保持读取 v1 单椭球和恒定圆管；
- 对 v2 多叶孔使用固定 Sobol 独立重算体积、包络、填充率、重心和连通性；
- 对 v2 通道从 HDF5 中心线/半径和 JSONL PCHIP 结点积分体积及端帽，重算 `eta`、`tau`、CV、鼓包/收颈、弯折、非平面和自交；
- 对声明了 `target_volume_A3` 的 v1/v2 单孔要求独立体积误差不超过 3%；不信任生成器写出的单孔体积声明。

生成器内部的 `p_V` 审核使用连续单孔几何体积，避免体素量化把 constant 分布误判；clipped 体积仍保留用于最终相位、重叠和边界诊断。

## 验收

- 同 seed 位级可复现，不同 seed 改变内部形状。
- 紧凑孔：2–4 叶、连通、`eta` ≤5%、体积 ≤3%、填充率 0.50–0.85。
- 通道：7 控制点、CV 0.15–0.30、鼓包+收颈、`eta/tau` ≤1%、体积 ≤3%、无自交。
- 全局缩放保持相似性，体积按 `scale^3`，`eta/tau` 不变。
- v1/v2 validator fixture 均通过。
- 串行、候选并行、seed 并行和 replay 保持科学几何一致。
- 40 通道低分辨率基准不超过基线 2 倍；记录峰值内存、段数、体素数和阶段耗时。
- 示例和正式计算数据只写入 `C:\Calculation_results\YYYY-MM-DD\python_results\...`。
- 完成后只提交实验分支，不部署、不合并、不覆盖全局 Skill。
